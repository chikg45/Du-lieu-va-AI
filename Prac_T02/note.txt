2. REQUIRED READING
--------------------------------------------------------------------------------

  (1) Lab-Data-Wrangling.ipynb
      Data Wrangling — chuyển dữ liệu từ dạng thô sang dạng phù hợp để phân tích.

      Nguyên lý cần nắm:
      - Identify and handle missing values
        (phát hiện missing, thay thế bằng mean / mode, hoặc drop hàng)
      - Correct data format (đổi kiểu dữ liệu đúng: int, float, object)
      - Data standardization (ví dụ: mpg → L/100km)
      - Data normalization (centering / scaling)
      - Binning (chia biến liên tục thành khoảng)
      - Indicator / dummy variables (biến chỉ thị cho biến phân loại)

  (2) Lab_Exploratory-Data-Analysis.ipynb
      Exploratory Data Analysis (EDA) — tìm đặc trưng ảnh hưởng mạnh đến giá xe.

      Nguyên lý cần nắm:
      - Chọn phương pháp trực quan phù hợp theo kiểu biến
        (số liên tục vs. phân loại)
      - Continuous numerical variables: scatter plot, hồi quy tuyến tính
      - Categorical variables: box plot
      - Descriptive statistical analysis (describe, value_counts)
      - Grouping (groupby)
      - Correlation vs. causation (Pearson correlation, p-value)
      - ANOVA (so sánh trung bình giữa các nhóm)

Lưu ý: hai file lab dùng để HỌC. Không nộp hai file lab này.
