YÊU CẦU NỘP BÀI — WEEK 7

Nộp ở hai nơi: GitHub và LMS. Thiếu một trong hai nơi thì bài chưa được tính là đã nộp.


1. GitHub

Trong repository cá nhân, vào thư mục practice.
Tạo thư mục week7 ngay bên trong practice:

    practice/week7/

Upload toàn bộ bài đã làm vào practice/week7/, rồi push lên GitHub.
Mỗi notebook phải được chạy lại trước khi nộp

Các file cần có trong practice/week7/:

    02_TH-kNN.ipynb
    04_Demo-kMeans-Template.ipynb
    06_TH-kMeans.ipynb
    08_Demo-DBSCAN-Template.ipynb
    09_TH-DBSCAN.ipynb
    10_TH-Clustering.ipynb
    11_Cauhoi-kNN-kMeans-DBSCAN.ipynb

File demo và file lý thuyết (01, 03, 05, 07) là tài liệu học, không cần upload.
Không upload thư mục data nếu file quá nặng. Notebook đã có output là đủ.


2. LMS

Nén thành một file zip đúng tên:

    week7_MSSV_HoTen.zip

Ví dụ: week7_22520001_NguyenVanA.zip

- MSSV là mã số sinh viên.
- HoTen viết không dấu, không khoảng trắng, hoa chữ cái đầu mỗi từ.

Bên trong zip có:

    week7/
        02_TH-kNN.ipynb
        04_Demo-kMeans-Template.ipynb
        06_TH-kMeans.ipynb
        08_Demo-DBSCAN-Template.ipynb
        09_TH-DBSCAN.ipynb
        10_TH-Clustering.ipynb
        11_Cauhoi-kNN-kMeans-DBSCAN.ipynb
        images/
            anh chụp GitHub

Ảnh trong images/ phải thấy được:

- Địa chỉ repository trên GitHub.
- Thư mục practice/week7/ và đủ các file bài làm đã push.
- Commit mới nhất (có ngày giờ).

Ảnh chụp màn hình rõ, không cắt mất tên file và đường dẫn.
